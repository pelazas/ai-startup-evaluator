# Founder Profile Signals

## Skills and domain background
Profile records should capture technical strengths, functional gaps, and prior domain exposure. Domain familiarity improves problem selection and customer language precision.

## Execution capacity
Founder bandwidth constraints matter for roadmap realism. Profiles should note available team size, decision speed, and implementation support from advisors or operators.

## Risk posture
A founder's risk tolerance and financial runway shape go-to-market timing, hiring strategy, and experimentation cadence. This context helps tailor recommendations beyond generic startup advice.
